# Writing Insights

Use this in your FINAL response after running code, not as code itself.

## Rules
1. Lead with the direct answer to the user's question in one sentence.
2. Support it with 1-3 concrete numbers from the actual `RESULT` output.
3. Avoid jargon (say "average" not "mean", "spread" not "variance") unless
   the user is clearly technical.
4. If you generated a chart, refer to it explicitly ("as shown in the chart above...").
5. End with one actionable takeaway or a suggested follow-up question if relevant.
